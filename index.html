Build an extra

This example follows the current PND26 extras loader. Folder names below are suggestions; the root manifest and its entrypoint are required. The entrypoint must export register(client).

PND26 does not install an extra's dependencies. Use APIs already available to the bot and account for dependency resolution on the host.

Submit an extra

  1. Create your repository

    Add your extra’s source, a license, and a package.json. Add a root nationdex.extra.json with the extra ID, API version 1, and a relative entrypoint that exports register(client). See the Example tab.

  2. Pin a reviewed commit

    Remote installation requires a full 40-character Git commit SHA. A branch name alone does not authorize installation.

  3. Add your catalogue entry

    For monorepos, set the optional path to the extra folder; omit it for a standalone repository. Fork nationdex/index and edit data/extras.json.

    {
  "id": "example",
  "repo": "https://github.com/yourusername/your-extra",
  "branch": "main",
  "path": "extras/example",
  "ref": "<reviewed 40-character commit SHA>"
}

  4. Open a pull request

    The catalogue lists extras. Each bot owner independently approves repositories and exact commits in their panel before installation is possible.
