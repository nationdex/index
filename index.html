Submit an extra

  1. Create your repository

    Add your extra’s source, a license and a package.json with its name, version, description and author. Follow the target instance’s extras manifest and registration requirements.

  2. Pin a reviewed commit

    Remote installation requires a full 40-character Git commit SHA. A branch name alone does not authorize installation.

  3. Add your catalogue entry

    Fork nationdex/index and edit data/extras.json.

    {
  "id": "example",
  "repo": "https://github.com/yourusername/your-extra",
  "branch": "main",
  "ref": "<reviewed 40-character commit SHA>"
}

  4. Open a pull request

    The catalogue lists extras. Each bot owner independently approves repositories and exact commits in their panel before installation is possible.
